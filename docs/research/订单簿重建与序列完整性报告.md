## 1. 结论：本机无法重建任何 A 股订单簿

订单簿重建需要以下之一，本机**全部不可得**：

| 前提 | 本机状态 | 证据 |
| --- | --- | --- |
| 逐笔委托（含委托编号、撤单事件） | 无供应商 | 能力矩阵 `level2_order_events` = 0 个 SERVING |
| 千档 / 多档委托队列 | 无供应商 | `order_queue` = 0 个 SERVING |
| Level-2 聚合快照 | 无供应商 | `level2_snapshot` = 0 个 SERVING |
| 交易所序列号 | 公开源不发布 | `sequence` 恒为空 |

因此本报告**不给出**任何订单簿重建结果，也**不给出**排队位置、撤单领先量、
价格-时间优先级的任何估计。给出这些数字需要本机没有的数据。

## 2. 序列完整性：为何判定为"无法评估"

`check_sequence_gaps` 的判定逻辑：

```
若 sequence 列全为空 → NOT_RUN，理由："provider publishes no exchange sequence
number; completeness cannot be proven from the stream alone"
```

本次 24,222 条事件全部落入该分支。

**关键纪律：`NOT_RUN` 不是 `PASS`。** `IntegrityReport.usable` 要求既无 `FAIL`
也无 `NOT_RUN`，故本数据集 `usable = False`。

同样落入 `NOT_RUN` 的还有：

| 检查 | 未能评估的原因 |
| --- | --- |
| `duplicate_events` | 无成交编号/委托编号，重复事件与"确实重复发生的观测"不可区分 |
| `sequence_gaps` | 无交易所序列号 |
| `cumulative_monotonicity` | 该源不发布 session 累计量 |
| `book_ordering` | 无盘口数据 |

我们能证明的是**流与日线一致**（对账 9/9 通过），**不能**证明**流本身完整**。
这两件事必须分开陈述。

## 4. 保真度的机械降级

`decide_fidelity()` 由数据**推导**回测保真度，策略作者无法自选：

| 数据类 | 授予等级 | 可宣称 |
| --- | --- | --- |
| `EXCHANGE_ORDER_EVENT` / `LEVEL2_ORDER_BOOK` | Level A | 排队位置、订单老化、前方撤单、价格-时间优先级 |
| `LEVEL2_SNAPSHOT` | Level B | 可见深度、深度耗尽、近似部分成交（**不含**排队位置） |
| `TRADE_TICK` / `LEVEL1_QUOTE` / `SNAPSHOT_DERIVED_TRADE_AGGREGATE` | Level C | 跨价成交、延迟、成交量参与 |
| 仅日线/分钟 | Level D | 仅 bar 收盘成交 |
| 语义未知 或 完整性 FAIL | `NOT_SIMULATABLE` | 无 |

两条额外的降级规则：

1. **未评估的检查会降级 Level A → Level B**，理由记录为
   "Level A requires proven sequence completeness"。即使拿到逐笔委托，若无法证明
   序列完整，也不授予排队位置。
2. **券商合成报价存在时，撤回 Level A/B**，降为 Level C，理由为"OTC/CFD 场所的
   深度不是交易所订单簿"。

**本次数据的实际判定 = Level C**，并附降级说明：

> "trade records are 3-second aggregates, not individual prints: intra-bucket
> sequencing, per-trade size distribution and any sub-3s latency claim are
> unobservable"

## 5. 硬性拒绝

`fidelity.assert_claims_permitted()` 在保真度不足时**抛异常**，而不是静默降级。
模拟器的 Level-B 成交模型显式把 `queue_position_shares` 置为 `None`，并有测试
`test_level_b_never_populates_queue_position` 锁定该行为。

静默降级是"Level-B 结果在报告里被写成 Level-A"的成因，因此设计上不留这条路径。
