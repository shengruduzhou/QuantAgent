## 1. 为什么不用单一 "ready"

一个布尔值无法承载"管线跑通了"与"这些数字可以用来选模型"之间的区别。把二者混同，
正是冒烟结果被当成业绩声明的方式。因此就绪被拆成**四张独立证书**，每张都同时声明
**允许什么**与**明确不允许什么**。

## 3. 各层的允许与禁止

### 3.1 `ENGINEERING_PIPELINE_READY`（已授予）

**允许**：UI 测试、有界数据集构建、单 epoch 冒烟训练、checkpoint 与 resume 校验、
非评价性作业。

**明确禁止**：策略排序、**业绩声明**、模型晋级、Paper 组合运行。

> 这层的存在意义就是：管线能跑 ≠ 可以拿数字说话。

### 3.2 `FULL_UNIVERSE_GOLD_READY`（未授予）

要求：可复现的 U0 原始→复权转换、全宇宙特征数据集、可执行标签、显式缺失掩码、
零重复 security-date 行、无上市前/退市后行、哈希与血缘齐全。

当前 8 项要求全部为 `UNKNOWN`（产物不存在）。

### 3.3 `FULL_UNIVERSE_RESEARCH_READY`（未授予）

要求：有效 PIT 宇宙、**有效 ST/\*ST 区间**、停牌区间、涨跌幅制度、公司行动处理、
purged walk-forward、embargo、成本与冲击模型、全宇宙基准。

**`st_intervals` 仍为强制字段，未被移除、未被弱化。** 证书 note 明确写明：

> strict PIT remains blocked on ['st_intervals']; this tier is withheld rather
> than relaxed, and st_intervals stays a mandatory field

### 3.4 `LOCAL_PAPER_READY`（未授予）

已具备：确定性 Paper Broker、完整事件账本、风控引擎、重启恢复、Kill Switch。
**尚缺**：经批准的研究模型（需先有 `FULL_UNIVERSE_RESEARCH_READY` 与 OOF 回测）。

## 4. 三条硬性判定规则（有测试）

1. **UNKNOWN 永不算 PASS** ——未评估的检查不是通过的检查。这正是历史上"闸门写成
   字面量 True"的翻版，本次从数据结构层面杜绝。
2. **前置层未授予则高层不授予**。
3. **低层的 forbid 压过高层的 allow** ——即使 Gold 层允许全宇宙训练，
   工程层禁止的"业绩声明"仍然被禁止。`permits()` 对未声明的动作**默认拒绝**。

## 5. LIVE_TRADING_READY

**刻意不实现。** `live_trading_certificate()` 返回结构化拒绝：

```json
{"tier":"LIVE_TRADING_READY","granted":false,"implemented":false,
 "reason":"NOT_IMPLEMENTED_BY_POLICY",
 "banner":"LIVE TRADING: DISABLED BY POLICY"}
```

且 `"LIVE_TRADING_READY" not in TIERS`（有测试）。

## 6. 安全边界（同批交付）

`src/quantagent/safety/operating_mode.py`：

- 运行模式枚举：`RESEARCH / HISTORICAL_REPLAY / BACKTEST / PAPER / SHADOW / LIVE_DISABLED`；
- `LIVE_DISABLED` 是**终态策略状态，不可执行**——用 `require_executable()` 断言；
- `live_trading_available` **无法被构造为 True**（构造即抛异常），因为一个声称有
  实盘能力的标志会被 UI 忠实显示出来；
- 实盘意图在**咨询 Agent、路由、创建作业之前**被拒绝，覆盖中文短语（实盘／真实下单／
  连接资金账户／自动买入／自动卖出／真实委托）、英文短语与券商 SDK 入口
  （`order_stock` / `order_stock_async` / `order_send` / `XtQuantTrader`）；
- 递归扫描嵌套参数与字典键，**并对只读的 `l2order` 行情源做了豁免**（否则会把
  Level-2 委托流探测误判为下单）；
- 两条 AST 静态扫描证明：无生产模块调用券商下单 API、无模块级导入交易客户端；
  第三条测试证明该扫描本身能抓到植入的违规。
