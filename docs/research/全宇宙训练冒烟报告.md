## 4. 过程中的两次自我纠正（如实记录）

**其一：学习率发散。** 首次 LR=0.01，loss 由 0.00511 升至 0.00636。一个发散的
循环无法证明优化步骤接好了，因此下调至 0.001。

**其二：first/last 单批对比是噪声。** 权重零初始化时，对均值≈0 的收益率做 MSE
本就接近最优，有界运行内**批间采样噪声主导任何趋势**。因此证据改为报告**窗口均值**：

```
mean_loss_first_10 = 0.005406
mean_loss_last_10  = 0.005369      ← 基本持平
```

并在证据文件中明确写入：

> Loss trend is NOT a smoke criterion and is reported for transparency only.

**冒烟的判据是**：loss 有限、checkpoint 原子写入、重载校验、恢复成功——
**不是** loss 下降。
