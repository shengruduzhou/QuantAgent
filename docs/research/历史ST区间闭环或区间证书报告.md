### 2.1 关键否定发现：新浪"曾用名"**没有日期**

`akshare.stock_info_change_name(symbol=...)` 是**逐标的**接口，返回值只有：

```
cols = ['index', 'name']
例：['琼海虹', '海虹控股', 'ST海虹']
```

**只有名称序列，没有任何生效日期。** 因此它**在原理上无法**产生 PIT 区间——
知道某只股票曾经叫过 "ST海虹"，但不知道从哪天到哪天。

### 2.2 上交所退市接口不是风险警示接口

`akshare.stock_info_sh_delist` 返回 159 行，字段为
`['公司代码','公司简称','上市日期','暂停上市日期']`——是**退市/暂停上市**信息，
不含 ST 实施与撤销事件。

## 4. 为什么区间证书也不成立（实证，非断言）

任务要求：若无法完全闭环，则测试"是否存在一个较晚的日期区间，使其中**每一个**
security-date 行的 ST 状态都已知"。

**答案是否定的，且原因是结构性的**：上交所 2,462 只与北交所 330 只证券在
**整个历史上的每一天**都没有任何带日期 ST 证据。因此不存在任何起始日期，能让
全宇宙的每个 security-date 都有已知 ST 状态。

唯一"全部已知"的时刻是当前快照的观测日（333 只当前 ST，观测于 2026-07-26），
那是**单个时点**，不是可用于研究的窗口；且任务明令**禁止把当前快照向历史投影**。

**因此本次不创建任何区间证书。** 造一个名字里带日期、实则大部分证券状态未知的
证书，比没有证书更危险。

## 5. 处置

- `mask_is_st` 在 Gold 中为**三态**：深交所有据可依处为 TRUE/FALSE，
  其余一律 **`UNKNOWN`**；
- **空结果绝不解释为"从未 ST"**；
- `FULL_UNIVERSE_RESEARCH_READY` 维持**未授予**，未met 项即
  `st_intervals_available` 与 `no_blocked_pit_fields`；
- 正式 OOF 研究评测**不得启动**。

## 6. 解除路径（唯一已识别）

券商 QMT 权限 + Windows 主机 → `xtdata.download_his_st_data()` /
`get_his_st_data()`，且必须带**阳性对照**（已知曾 ST 的标的）：若阳性对照也返回空，
则判定数据集不可用，**任何标的都不得记为 never-ST**。

该探测器已实现（`QmtGateway.probe_st_with_controls`），等待硬件与权限。
