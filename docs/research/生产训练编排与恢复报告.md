## 1. 核心保证：PID 不等于"作业在跑"

一个陈旧 PID 文件、一个被 OOM 杀掉的进程、一次主机重启，**留下的记录看起来都像
存活**。因此存活判定同时要求：

1. 进程存在（`os.kill(pid, 0)`）；
2. **心跳新鲜**（默认 180 秒内）。

四种判定，互不混淆：

| verdict | 含义 |
| --- | --- |
| `ALIVE` | 进程在 + 心跳新鲜 → `observably_running = true` |
| `STALE_PID` | 记录了 PID 但进程不存在 |
| `STALE_HEARTBEAT` | **进程存在但心跳过期**（PID 可能被系统回收给了别的进程） |
| `NOT_ACTIVE` | 当前状态本就不该有进程 |

均有测试覆盖，包括"进程活着但心跳过期"这一最容易误报为 RUNNING 的情形。

## 2. 16 态生命周期

```
DRAFT → VALIDATING → VALIDATED → FROZEN → ARMED → QUEUED → STARTING
     → RUNNING ⇄ CHECKPOINTING
     → PAUSING → PAUSED → RESUMING → RUNNING
     → COMPLETED | FAILED | CANCELLED | QUARANTINED
```

跃迁**被强制**，非法跃迁抛 `LifecycleError`。

## 3. 三道防止"未审配置进入 GPU 队列"的闸门

1. **未 FROZEN 不可 ARM**；
2. **ARM 必须回填冻结哈希**——调用方要把 `configuration_hash` 原样传回，
   因此**无法 arm 一个自己没看过的配置**，UI 的确认步骤成为证据而非走过场；
3. **未 ARMED 不可 launch**。

冻结后若编辑配置，状态回到 `DRAFT`——一个冻结哈希永远不会描述一个已被改动的配置。

## 4. 运行清单（可复现所需的全部）

`run_id / experiment_id / source_commit / dataset_hash / schema_hash /
feature_hash / label_hash / fold_hash / configuration_hash / model_family /
horizon / seed / host / gpu / pid / heartbeat / started_at / updated_at /
checkpoint_path / latest_epoch / best_epoch / status / failure_reason / history`

配置哈希**覆盖数据哈希**，因此数据集被重建后旧配置会在 preflight 处失败，
而不是产出不可比的数字。

## 5. Preflight 保护

| 检查 | 失败示例 |
| --- | --- |
| `dataset_exists` | 路径不存在 |
| `dataset_hash_matches` | "数据集在配置冻结后被重建" |
| `schema_hash_matches` | schema 漂移 |
| `folds_defined` / `no_empty_train_fold` / `no_empty_validation_fold` | 空折 |
| `sufficient_disk` | 剩余空间不足 |
| `gpu_available_if_required` | 要求 GPU 但不可用 |

preflight 失败 → 运行进入 `FAILED` 并记录原因，**不放行**。

## 6. Checkpoint 完整性

- **原子写**：先写 `.tmp` + `fsync`，再 `os.replace`；测试断言不残留 `.tmp`；
- **摘要旁路文件**：`.sha256`；
- **重载校验**：摘要不符抛 `ValueError: ... corrupt`——
  一个能加载的截断 checkpoint 比一个加载失败的更危险；
- **NaN/Inf loss 立即停**：`guard_loss` 抛 `PreflightError`，
  机器可读代码 `non_finite_loss` 在 `.failures`，人读信息在消息里。

## 7. clone 不继承结果

克隆只复制配置，**不复制** PID、心跳、checkpoint、best_metric、history。
否则克隆会把上一个 run 的数字报成自己的。

## 8. 持久化

manifest 采用**原子写**（`.tmp` + `os.replace`），崩溃不会留下截断的 manifest；
`TrainingRun.load()` 可完整还原状态与历史。
