## 1. 规则带生效日，不硬编码"今天的规则"

规则会变。把旧值写死等于回测一个已不存在的市场，因此每个常量带来源与生效日，
查询函数接受交易日参数。

| 规则 | 值 | 生效 |
| --- | --- | --- |
| 印花税 | **0.05%，仅卖出** | 2023-08-28 起（此前 0.10%） |
| 过户费 | 0.001%，双边 | — |
| 佣金 | 默认 0.025%，最低 5 元 | 建模输入，可覆盖 |
| 主板新股无涨跌幅 | **前 5 个交易日** | 2023-04-10 全面注册制起 |
| 主板新股（注册制前） | +44% / −36% | 2023-04-10 之前 |

## 5. 费用方向性（实测）

```
买入 100,000 元：佣金 25.0 + 过户费 1.0 + 印花税 0.0  = 26.0
卖出 100,000 元：佣金 25.0 + 过户费 1.0 + 印花税 50.0 = 76.0
```

有对照测试断言买入印花税为 0、卖出为正。

## 6. 公司行动

送转按比例缩放股数**并反向缩放平均成本**，使账面价值不变——否则会在除权日
凭空制造或销毁 P&L。分红按持股数计入现金。均有测试。

## 7. 保真度边界（不得夸大）

当前为日线数据，因此：

- 成交按会话成交量参与 + 平方根冲击建模；
- **不声称排队位置**；
- 不做 3 秒以下的延迟结论。

要进入 Level A（排队位置、订单老化、前方撤单）必须先有真实逐笔委托与成交，
当前**不具备**。
