## 5. AkShare 真相（R5 + ENG_AKSHARE，实测）

你一直感觉 “akshare 数据不太对” 是**对的**，原因有四层：
1. 实际被使用的 v7 银层面板把**前复权价格**（随抓取日期变化）和**原始成交量/额**拼在一起，却标记
   `point_in_time_valid=True`：2021–2025 年 412.6 万行中 332.5 万行价格非原始。
2. 东方财富来源的 15,971 行成交量是“手”不是“股”（恰为 U0 的 0.01×）。
3. 不同来源的“qfq”含义不同：东财/腾讯是减法平移，新浪是乘法因子。
4. 腾讯接口：科创板成交量被放大 100 倍；akshare 1.18.84/1.19.1 对 `sz000*` 少乘 100。
修复后实时冒烟（5 个跨板块标的，2024-01，原始价）与 U0 原始 K 线 close/volume/amount 比值全部 1.000。
v7 银层面板本身未重建（已由单位审计脚本标记为 REFUTED），规范评估器已不再默认使用它。
