## 1. 前后端契约一致性 / Frontend↔backend contract

**方法**：前端 API 客户端层是单一的 `apps/quant-ui/src/api/client.ts`
（`apiGet` / `apiPost` / `apiDelete` / `apiEventSourceUrl` / `apiWebSocketUrl`），
GET 统一经 `apps/quant-ui/src/hooks/useApi.ts:11` 的 `useApi<T>()`。
穷举了 39 处 `apiPost/apiDelete/apiWebSocketUrl/apiEventSourceUrl` + 96 处 `useApi<...>` 调用点，
逐条比对 `services/quant_api/routes/**` 的 132 个路由装饰器（前缀：`api.py`=`/api`、
`market.py`/`fuyao_playbooks.py`=`/api/market`、`parity.py`=`/api/system`、
`production_readiness.py`=`/api/governance`、`paper_execution.py`=`/api/paper`、
`walkforward_risk.py`=`/api/walkforward-risk`、`events/routes.py`=`/api/events`）。

### 1.1 前端调了但后端没有 —— **0 条**

`isJobType` 白名单约束（`backtest|train|infer|factor-discovery|factor-evaluation`），
